# Assets Folder

This folder should contain the following image assets for the WinUI 3 application:

## Required Files

1. **TrayIcon.ico** (16x16, 32x32 pixels)
   - System tray icon displayed when the app is minimized

2. **Square150x150Logo.png** (150x150 pixels)
   - Medium tile logo for the application

3. **Square44x44Logo.png** (44x44 pixels)
   - Small app logo used in taskbar and Start menu

4. **Wide310x150Logo.png** (310x150 pixels)
   - Wide tile logo for the application

5. **StoreLogo.png** (50x50 pixels)
   - Logo for the Microsoft Store listing

6. **SplashScreen.png** (620x300 pixels)
   - Splash screen displayed when the application launches

## Creating Placeholder Assets

For development purposes, you can create simple placeholder images using any graphics tool. For a production application, these should be professionally designed icons that match your brand.

### Quick Placeholder Creation

You can use online tools or image editors like:
- Paint.NET (Windows)
- GIMP (Cross-platform)
- Adobe Photoshop
- Figma
- Online icon generators

### Temporary Solution

If you need to build immediately without proper assets, you can create simple solid-color PNG files with the dimensions listed above. However, the TrayIcon.ico must be a proper .ico file for the system tray to work correctly.

## Asset Guidelines

- Use transparent backgrounds where appropriate
- Ensure icons are clear and visible at small sizes
- Follow Windows 11 design guidelines for modern appearance
- Use consistent color scheme across all assets
- Ensure icon is recognizable at 16x16 size (tray icon)
